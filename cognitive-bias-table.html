How it is arranged

Columns are kinds of decision, not kinds of thinking — the eight rooms where these errors actually cost something. Nine biases to a group, numbered across the rows. Before a decision of one kind, read that column.

The dot

Each element carries a second mark: the mental shortcut underneath it — too much information, not enough meaning, the need to act fast, or the limits of memory. Different columns, same four causes.

Bonds

Hover an element to see the biases it reinforces. Few act alone: anchoring feeds framing, sunk cost leans on loss aversion, and the blind spot covers all of them.

Counter-moves

Every card ends with one. Knowing a bias by name does not dissolve it — the fixes that work are procedural: written predictions, fixed criteria, outside views, and someone else holding the pen.
